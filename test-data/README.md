# Leaf test data

Keep reusable recordings and the evidence needed to interpret them here. Device and
simulator screen captures for documentation belong in
[`docs/assets/device-captures`](../docs/assets/device-captures/README.md).

- [October 25 and 27 field testing](field-testing/README.md): original IGC recordings,
  logbook files, analysis scripts, saved reports, and replay inputs.

Collection folders retain their original device names and filenames. The collection
date is not necessarily the flight date: a device download can contain older flights.
