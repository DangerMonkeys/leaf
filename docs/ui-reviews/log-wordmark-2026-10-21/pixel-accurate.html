LOG · pixel-accurate display comparison

All eight wordmarks sit on a fixed 96 × 32 Leaf-pixel strip. Letter placement is baked into the bitmap at whole-pixel coordinates.

1× = one physical screen pixel per Leaf pixel. Enlarged views use exact integer blocks. The page adjusts for browser zoom and display density, and aligns each bitmap to the physical pixel grid.
