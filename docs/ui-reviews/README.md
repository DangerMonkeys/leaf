# UI reviews

Keep feature-specific review galleries, native screenshots, capture scripts,
manifests, and verification notes in this directory. Each review should explain
how its images were produced and identify its firmware or source revision when
known.

Reusable screen images and animations for manuals and website documentation live
in [`docs/assets/device-captures`](../assets/device-captures/README.md). Review
galleries can link there when an image is useful beyond the original review.
