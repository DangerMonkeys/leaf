Leaf SD screens

90 native screenshots · 70 distinct frames · firmware source c7c9e6f1 + rounded SD dialogs (working tree)

Rounded SD message panels, centered text, and IGC wording. The inline summary warning retains its existing layout.

Standalone message overview

Saving and flight summaries · Logbook: normal, deletion and data states · Repair outcomes and menu context · Charging, upload and USB states · Charging and upload animation frames
Scope, provenance and screens that intentionally do not exist
  • Actual 96×192 u8g2 firmware frames; no mockups. Synthetic data only; user SD evidence was not used.
  • Firmware source: c7c9e6f1 + rounded SD dialogs (working tree). Standalone SD messages use centered 96×96 rounded frames; the inline summary save-failure warning is unchanged.
  • Saving and shutdown-failure messages were captured inside the real stop path, before staging open and during the failure-notice delay respectively.
  • Charging uses the existing charging_dialogs regression harness and deterministic transport outcomes; it checks the reference animation artwork.
  • The charging footer retains the simulator's 0.0.0+build.script.error placeholder. It is not an SD error or a release build version; no footer pixels were edited.
  • Removed Not fully deleted messages are absent in the current firmware. Quiet partial-delete captures demonstrate the replacement behavior.
  • No repair-success, repair-deferred, or cleanup-failure dialogs exist. Repair outcomes appear through the available logbook entries and counts.
  • Manual and automatic stops share the same summary renderer. Power-off and low-battery failure notices use the same message.
  • Web-app Checking logs... is HTML, not a firmware LCD screen; it is outside this native screenshot set. Unrelated GPX/profile/formatting tools are also outside this set.

Regenerate this review set

In the normal GCC simulator container, from the repository root (with dependencies available):

make -C sim -j8 /leaf/sim/build/sd_dialogs_capture /leaf/sim/build/charging_dialogs_test
LEAF_CAPTURE_COMMIT=<firmware-commit> ./sim/build/sd_dialogs_capture docs/ui-reviews/sd-card-dialogs
./sim/build/charging_dialogs_test docs/ui-reviews/sd-card-dialogs/screenshots/charging

Then, using Python with Pillow installed:

python sim/scripts/build_sd_dialog_gallery.py docs/ui-reviews/sd-card-dialogs
