<section className="manual-first-flight">
  <h2 id="before-your-first-flight">Before Your First Flight</h2>

- Fully charge Leaf using a USB-C cable.
- Read the liability waiver included with Leaf. Leaf will ask you to accept it the first time you turn it on. You can disable this reminder later in <strong>Menu &rarr; Settings &rarr; System</strong>.
- Under Main Menu → Settings, turn on Vario → Quiet Mode to keep Leaf quiet until your flight starts, and <strong>Logging → AutoStart</strong> to start the flight timer automatically at launch. Set your local time zone under System.
- <span>You may wish to <a href="#firmware-updates">update to the latest firmware</a>.</span>
- Mount Leaf using the Velcro strap or base plate, and always attach the lanyard.
- Test Leaf on the ground before flying.

<strong>First GPS fix:</strong> Leaf may take 10-15 minutes to acquire its first GPS fix. Place it outside with a clear view of the sky. Subsequent fixes should be faster after initial satellite data is saved.

### Accessing the SD card

<div>

<p>Turn Leaf off and connect it to your computer or phone with a USB cable. Open the LEAF VARIO drive to access the SD card.</p>
<p>If Leaf Log is uploading flights, wait for uploads to finish or press <strong>CENTER</strong> twice to cancel them and open the drive.</p>

</div>

<br />

<div>

<p>Leaf charges over USB whether it is on or off, but the USB drive is available only while Leaf is off. Safely eject the drive before unplugging Leaf or turning it on.</p>

</div>

<h3 id="saving-track-logs">Saving Track Logs</h3>

<div>

<p>To save your flight path as an IGC track file, turn on <strong>Main Menu → Settings → Logging → Save IGC</strong>. Recording begins when the flight timer is running and Leaf has a GPS fix. After landing, stop the timer manually or let AutoStop stop it for you.</p>

</div>

<div>

<div className="manual-shortcut-callout">
  <img src={buttonCenter.src} alt="Center button shortcut" />
  <p><strong>Shortcut:</strong> You can simply hold the center button at the end of a flight to turn off Leaf, even while the timer is running. While shutting down, Leaf will end the log and save the track file. Leaf will also save a running log if the battery runs out while recording.</p>
</div>

<p>Short recordings may show dashes for some flight statistics.</p>

<h3 id="repairing-the-logbook">Repairing the Logbook</h3>

<p>If the Logbook shows <strong>Repair needed</strong>, stop the flight timer and back up important SD card files to your computer. With the SD card in Leaf, open <strong>Settings → Logging → Repair Logs</strong> and follow the result shown on screen. Press <strong>LEFT</strong> or <strong>CENTER</strong> to cancel.</p>
<p>Repair Logs can recover interrupted flight summaries, but cannot restore a deleted track file.</p>

</div>

### Files and Folders

Leaf will create folders and files on the SD card as you use different features:

<ul className="manual-folder-list">
  <li><strong>tracks/</strong> Stores recorded IGC flight track files.</li>
  <li><strong>logbook/</strong> Stores the flight summaries shown in Leaf’s Logbook and Web App.</li>
  <li><strong>waypoints/</strong> Stores waypoint files for navigation. Copy <strong>GPX</strong>, <strong>CUP</strong>, <strong>WPT</strong>, or <strong>WYP</strong> files here. User waypoints saved on Leaf are also stored in this folder.</li>
  <li><strong>routes/</strong> Stores saved routes.</li>
  <li><strong>profiles/</strong> Stores pilot and glider profiles saved through the Web App.</li>

# Navigation

<h2 id="waypoints-and-routes">Waypoints and Routes</h2>

<p>Leaf can load waypoint and route files from the SD card. Save waypoint files in the <strong>waypoints</strong> folder on the “LEAF VARIO” drive, or import a waypoint file from your phone using the <a href="#loading-waypoints">Web App</a>. Leaf accepts <strong>GPX</strong>, <strong>CUP</strong>, <strong>WPT</strong>, and <strong>WYP</strong> files. GPX files may contain waypoints, routes, or both.</p>

### Loading and Activating Files

On Leaf, open <strong>Main Menu &rarr; Nav Data &rarr; Load File</strong>, then choose the file you want to use.

<div>
  <p>The Nav Data page shows the loaded file and the number of waypoints and routes it contains. Choose <strong>Navigate To</strong> to select your destination. If you load a saved route from the routes folder, navigation starts automatically.</p>
  <p>File limits: Up to <strong>20 points</strong> per route and <strong>120 waypoints</strong> per loaded file. A GPX file can load up to 10 routes with 80 route points in total; a point used in two routes counts twice. Files over the point limits will not load, and only the first 10 routes are loaded.</p>
  <p>Loading another file replaces the waypoints and routes currently in use. <strong>Clear All</strong> stops navigation and unloads them. Neither action deletes your saved files.</p>
</div>

### Selecting a Route or Point

Open <strong>Main Menu &rarr; Nav Data &rarr; Navigate To</strong> to choose a waypoint or route from the loaded file.

<p>Leaf shows your destination under <strong>Active Point/Route</strong>. Each route point has a circular area around it, called a cylinder. If no cylinder radius is defined, Leaf uses 400 m. With the flight timer running, Leaf uses GPS to detect when you enter the cylinder and automatically guides you to the next point. To skip a point or go back, use the destination-field shortcut below.</p>

<br />

When you select a route from a GPX file, or create or import a route from the Leaf Web App, Leaf automatically creates and saves a route file in the <strong>routes</strong> folder on the SD card. Saved routes can be loaded again later from <strong>Main Menu &rarr; Nav Data &rarr; Load File</strong>.

### WiFi Troubleshooting

Having issues connecting Leaf to WiFi networks? You can try the following:

<p>Try these steps in order:</p>
<ol>
  <li>Exit and reopen the Main Menu to retry the connection.</li>
  <li>Check that the network supports 2.4 GHz and that its name and password are correct. Leaf remembers only three networks, so you may need to add an older one again.</li>
  <li>Unplug Leaf from USB power, then turn it off and on again.</li>
  <li>If it still will not connect, select <strong>Settings → Connect → WiFi Reset</strong> and repeat WiFi Setup. WiFi Reset erases all saved networks.</li>
</ol>

### Reloading Firmware Manually

**WARNING** *Manually loading firmware is only for advanced users. For general updates, please use the firmware update process described above.*

<div>

**Make sure the firmware file matches your exact Leaf hardware version. Contact us if you are unsure.**

</div>

There are two methods for manually loading firmware:
#### Flash firmware via the SD card
<div>

Plug Leaf into your computer with a USB cable and leave it off in charging mode. Wait for Leaf Log to finish, or press CENTER twice to confirm cancellation, so the removable drive appears. Copy the new firmware file into the `firmware/` folder on the SD card, safely eject the drive, then unplug Leaf from the USB cable and reboot Leaf. During startup, Leaf will detect the firmware file and attempt to upgrade to the new firmware.

</div>

After the upgrade attempt, Leaf will create a status message inside the `firmware/` folder so you can confirm whether the update succeeded or failed. When you are finished, it is okay to delete the firmware file and the status message from the SD card.

#### Flash firmware via USB cable and programming tools

For advanced users who wish to reprogram the firmware manually, the "Boot" button is located behind the smallest speaker hole. To enter bootloader mode, turn Leaf off, then press and hold the Boot button while plugging in the USB cable, then release the Boot button. Or, while already plugged into USB, press and hold the "Boot" button then press and release the "Reset" button, then release the "Boot" button. Once in bootloader mode, the firmware can be uploaded using Arduino, PlatformIO, or Espressif tools.

### Restore Factory Defaults
To return all settings to the factory configuration, go to <strong>Menu &rarr; Settings &rarr; System</strong>, then scroll down to the Reset option. Hold the center button to reset all Leaf settings. This will reset Leaf settings and saved WiFi networks, but it will not erase your SD card, logs, pilot or glider profiles, or saved waypoints/routes.

### Hard Reset Leaf
Performing a hard reset is useful if Leaf becomes frozen or unresponsive. The reset button is hidden behind the speaker grille. Press a paperclip or pin into the lower-end of the largest speaker slot to hard reset Leaf. This will force a reboot, but it won't reset your user settings or touch your SD card. After you reset Leaf, you will need to turn it on again if it wasn't plugged into a USB cable at the time.
