## Before Your First Flight

- Fully charge Leaf using a USB-C cable.
- Read the liability waiver included with Leaf. Leaf will ask you to accept it the first time you turn it on. You can disable this reminder later in <strong>Menu &rarr; Settings &rarr; System</strong>.
- Explore the menu and adjust your preferences. We recommend turning on <strong>Vario &rarr; QuietMode</strong> and <strong>Logging &rarr; AutoStart</strong>, and setting your local time zone in <strong>Settings &rarr; System</strong>.
- Mount Leaf using the Velcro strap or base plate, and always attach the lanyard.
- Test Leaf on the ground before flying.

<strong>First GPS fix:</strong> Leaf may take 10-15 minutes to acquire its first GPS fix. Place it outside with a clear view of the sky. Subsequent fixes should be faster after initial satellite data is saved.

<br />

<strong>Stay connected:</strong> We love hearing feedback, ideas, and flight experiences. Chat with us on <a href="https://discord.gg/7Secr9MVF">Discord</a> or <a href="mailto:leafvario@gmail.com">Email</a>.

# SD Card & Logging

![SD card](leaf-sd-card.png)

### Accessing the SD card

Leaf functions as a mass-storage device. Simply plug it in to any computer or smartphone and you should see a "LEAF VARIO" drive appear with the SD card contents.  
*Note: a second drive may also appear with the firmware files. This can be ignored as it is only used for the rare occasion when you may wish to manually update the firmware.*

### Saving Track Logs

Flight logs will save to the SD card. Be sure to turn on the "Save IGC File" setting inside the Log Menu.

Track logs are saved in IGC format.

### Files and Folders

Leaf will create folders and files on the SD card as you use different features:

<ul className="manual-folder-list">
  <li><strong>tracks/</strong> Stores recorded IGC flight track files.</li>
  <li><strong>logbook/</strong> Stores flight summary files used by the Logbook page and Leaf Web App. These summaries reference the matching track files in <strong>tracks/</strong> when an IGC track was recorded.</li>
  <li><strong>waypoints/</strong> Stores waypoint files for navigation. You can place <strong>GPX</strong>, <strong>CUP</strong>, <strong>WPT</strong>, and <strong>WYP</strong> files here. Leaf also stores saved user waypoints in <strong>waypoints/user_waypoints.json</strong>.</li>
  <li><strong>routes/</strong> Stores route files created or imported on Leaf or in the Leaf Web App. Leaf may also use <strong>routes/active.json</strong> to remember the currently active route.</li>
  <li><strong>profiles/</strong> Stores pilot and glider profile information, such as <strong>profiles/profiles.json</strong>, after profiles are edited in the Web App.</li>
  <li><strong>diagnostics/</strong> May appear when diagnostic features are enabled or troubleshooting information is saved.</li>
  <li><strong>buslogs/</strong> May appear when developer logging is enabled.</li>
</ul>

# Navigation

### Waypoint and Route Files

Leaf can load waypoint and route files from the SD card. Save navigation files in the <strong>waypoints</strong> folder on the "LEAF VARIO" drive.  Leaf accepts <strong>GPX</strong>, <strong>CUP</strong>, <strong>WPT</strong>, and <strong>WYP</strong> files. GPX files may contain waypoints, routes, or both.

### Loading and Activating Files

On Leaf, open <strong>Main Menu &rarr; Nav Data &rarr; Load File</strong>, then choose the file you want to use.

After a file is loaded, the Nav Data page shows the active file name and the number of points and routes found. Use <strong>Clear All</strong> to unload the current navigation data.

### Selecting a Route or Point

Open <strong>Main Menu &rarr; Nav Data &rarr; Select Dest</strong> to choose a waypoint or route from the loaded file.

When a destination is selected, Leaf shows it under <strong>Active Point/Route</strong>, and the Nav Page will guide you toward the active waypoint. If you select a route, Leaf starts from the first waypoint in the route and advances through the route as you fly.

<br />

When you select a route from a GPX file, or create or import a route from the Leaf Web App, Leaf automatically creates and saves a route file in the <strong>routes</strong> folder on the SD card. Saved routes can be loaded again later from <strong>Main Menu &rarr; Nav Data &rarr; Load File</strong>.

After a successful connection, Leaf will save that network and try to reconnect automatically every time you open the Leaf menu. Leaf will save up to three of your last-used networks. You may wish to save your phone's hotspot network into Leaf as well, so you can use WiFi features out in the field.

<br />

When Leaf is connected to a network with internet access, you will be able to check for firmware updates, access the Leaf Web App from any device on that network, and, coming soon, automatically upload your IGC log files to a web-based logbook.

### Connecting to a Phone Hotspot

If a WiFi network is not currently available, but you need to use internet-required features on Leaf such as checking for firmware updates or uploading logs, you can connect Leaf to your phone's hotspot.

<br />

Remember that for local Leaf Web App functions, like editing waypoints/routes and viewing your logbook, you do not need internet or a hotspot. You can have your phone connect to Leaf directly.

<br />

To connect to your phone's hotspot network for internet access, follow this process:

1.  Turn on and configure the WiFi hotspot feature on your phone/device. Be sure to remember the hotspot network name and password.
2.  Follow the [Connect to WiFi](#connect-to-wifi) steps to connect to the Leaf network and open the WiFi setup page on your phone/device.

    **Note:** Connecting to the Leaf network on your device may automatically turn off your hotspot feature. If this happens, it is ok.

3.  Enter your hotspot network and password information into the WiFi setup page. If your hotspot did turn off, you may have to type the name manually instead of selecting it from the list.
4.  Immediately after clicking "Save and Connect", turn your device's hotspot feature back on if needed.
5.  Leaf will try to connect to the hotspot network and save it for future use.
6.  To reconnect in the future, simply turn on your hotspot feature before opening the main menu on Leaf. When the main menu page opens, Leaf will automatically try connecting to every saved network, including your hotspot.

<div className="manual-note-callout">
  <p><strong>iPhone hotspot note:</strong> Connecting Leaf to an iPhone hotspot may require another device, such as a tablet, laptop, or a friend's phone. Turn on your iPhone hotspot, then use the other device to follow the normal Leaf WiFi setup process and select the iPhone hotspot as the network Leaf should join.</p>
</div>

### WiFi Troubleshooting

Having issues connecting Leaf to WiFi networks? You can try the following:

- Try the WiFi setup process again, and make sure you are using the correct network name and password.
- Try rebooting Leaf by turning it off and on again. Leaf needs to be unplugged from a charger during this process for a proper reset.
- Fully reset WiFi settings by selecting <strong>Settings &rarr; Connect &rarr; Wifi Reset</strong>. Then try connecting again. <strong>Warning:</strong> this will erase all previously saved networks.

# Firmware Updates

Leaf can update to the latest firmware over WiFi. If you have not saved a network yet, follow [Connect to WiFi](#connect-to-wifi) first.

<br />

To check for updates, open <strong>Main Menu &rarr; Settings &rarr; System &rarr; Update FW</strong> on Leaf. Leaf will check for the latest firmware and restart when finished checking or updating.

<br />

If Leaf ever fails to properly check for updates, it is ok to restart Leaf and try checking again.

<br />

If no WiFi network is available, you can still check for firmware updates using your phone's hotspot and cellular connection. See [Connecting to a Phone Hotspot](#connecting-to-a-phone-hotspot).

# Troubleshooting

### Restore Factory Defaults
To return all settings to the factory configuration, go to <strong>Menu &rarr; Settings &rarr; System</strong>, then scroll down to the Reset option. Hold the center button to reset all Leaf settings. This will not erase your SD card or logs.

### Hard Reset Leaf
Performing a hard reset is useful if Leaf becomes frozen or unresponsive.  The reset button is hidden behind the speaker grille.  Press a paperclip or pin into the lower-end of the largest speaker slot to hard reset Leaf.  This will force a reboot, but it won't reset your user settings or touch your SD card.  After you reset Leaf, you will need to turn it on again if it wasn't plugged into a USB cable at the time.

### Reloading Firmware Manually

**WARNING** *Manually loading firmware is only for advanced users. For general updates, please use the [firmware update process](#firmware-updates) described above.*

**If you are manually loading firmware, you MUST be sure to use the correct firmware version for your specific Leaf hardware version.  For most users, this will be 3.2.7_release.  If you are unsure, please contact us before proceeding.**

There are two methods for manually loading firmware:
#### Flash firmware via USB drive
When plugging Leaf into a computer, you will see two removable drives appear.  One is the SD card, labeled "LEAF VARIO", where you'll find tracklogs and waypoint files.  The other drive is the processor boot partition, which can be used to update firmware.  Simply drag and drop the new firmware file onto this drive.  Leaf will reboot to the new firmware once the file is transferred and loaded.  **DO NOT UNPLUG** Leaf until the process is complete.

#### Flash firmware via USB cable and programming tools

For advanced users who wish to reprogram the firmware manually, the "Boot" button is located behind the smallest speaker hole.  To enter bootloader mode, turn Leaf off, then press and hold the Boot button while plugging in the USB cable, then release the Boot button.  Or, while already plugged into USB, press and hold the "Boot" button then press and release the "Reset" button, then release the "Boot" button.  Once in bootloader mode, the firmware can be uploaded using Arduino, PlatformIO, or Espressif tools.
