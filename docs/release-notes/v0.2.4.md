Leaf v0.2.4

## Leaf Vario firmware

### A. New features

- Customize climb and sink sounds in the Leaf Web App: adjust pitch, beep timing, and when tones start. Preview individual tones or run a climb/sink sound test on your Leaf.
- Adjust vario volume, sensitivity, Quiet Mode, and climb/glide averaging from the Web App's new Settings page.

### B. Improvements

- Smoother vario sounds, with fixes for clicks and abrupt pitch changes.
- Clearer Leaf Log charging screens show connection progress, flight upload counts, and when uploads are complete or paused.
- The Connect menu now shows your Leaf's Bluetooth name and connection status.
- GPS altitude sync at the start of a flight log is now enabled by default for new or reset settings.
- Leaf Log linking now includes a way back to the Web App, with a clearer confirmation before unlinking.

### C. Bug fixes and stability

- Turning the sink alarm off now fully silences sink tones; enabled tones start at the selected threshold.
- More reliable Bluetooth discovery, reconnection, and shutdown.
- Leaf continues operating if the temperature/humidity sensor is unavailable, and skips the unavailable temperature display.
- More accurate battery percentage estimates while charging.
- Fixed cases where a factory-network search could block Leaf Log uploads or access to the USB drive.

## Other tools and support

### A. New features

- New browser-based Thermal Training tool with guided lessons and solo practice. Learn to center thermals, use vario sounds, correct for wind, and choose a turn direction. https://leafvario.com/labs/thermal-training/

### B. Improvements

- Expanded the user manual with Leaf Labs, thermal displays, vario settings, Leaf Log pairing, upload status, and USB access guidance.
- Refreshed the Leaf website's browser icon.

### C. Bug fixes and stability

- Fixed simulator build and startup issues, and kept it compatible with the updated firmware.
- Corrected simulator sound timing so beeps play with more accurate spacing at different playback speeds.
